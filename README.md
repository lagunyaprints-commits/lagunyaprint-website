## 🤔 Why Images Might Look "Missing"

If you don't see images, ONE of these is the reason:

### Problem 1: Opening HTML directly from ZIP
**Bad:** Opening HTML file from inside the ZIP without extracting  
**Solution:** Extract the zip first, then open HTML

### Problem 2: Moved HTML without images folder
**Bad:** Moving only the HTML file, leaving images folder behind  
**Solution:** Always keep HTML files and `images/` folder together

### Problem 3: Wrong folder structure
**Bad:** `Desktop/index.html` + `Desktop/somefolder/images/`  
**Good:** `Desktop/website/index.html` + `Desktop/website/images/`
